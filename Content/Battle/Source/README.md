# Battle-Testgrafiken

Diese drei eigens erzeugten, auf eine sparsame UI-Größe verkleinerten Platzhalter gehören zur separaten Battle-Testoberfläche:

- `T_BattleGlen.jpg`: gemalte Naturkampffläche, 1280 × 720 Pixel.
- `T_TestWater.png`: transparente Spieler-Kreatur.
- `T_TestGrass.png`: transparente Gegner-Kreatur.

Die Laufzeit lädt die importierten Unreal-Texturen unter `/Game/Battle/Textures`. Die Quellen bleiben für eine spätere visuelle Überarbeitung erhalten. Die Kreaturengrafiken sind keine endgültigen Art-Designs; Namen, Werte und BattleSession kommen weiterhin aus den vorhandenen Testdaten.
